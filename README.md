# CU-expand-russification

## Вкратце о руссификаторе

Неофициальный перевод Casualties: Unknown от CheBuRek8176. В тестировании участвовали Roketuss, PROPELLER22869, Bulaga, Komarok, dok_vazelin и Day1xt.

Данный руссификатор был сделан на базе другого руссификатора с официального репозитория, но в итоге был почти полностью переписан из-за корявости перевода. Ссылку на оригинал, увы, я где-то потерял, и вообще я нашёл его, внимание, в Pull Requests.

Идею "расширения" взял из очень древнего руссификатора аш для demo v1, увы, ссылки нет. Его всё ещё можно найти среди первых постов на официальном сайте игры на itch.io. А идею советов взял из Project Silverfish.

На других версиях будут многочисленные баги.

**В настоящий момент руссификатор находится в разработке, и в нём много опечаток и отсутствующих переводов. И ты можешь помочь ему! Предлагай предложения по переводу в Pull Requests или Issues**

## Установка

- Скачай JSON-файл (пока что я не особо разбираюсь в этом, так что тыкаешь на файл в репозитории, затем на три точки и затем на Download, либо на файл, затем на Download raw file), либо во вкладке Releases
- Закинь файл по пути: C:\Program Files (x86)\Steam\steamapps\common\Casualties Unknown Demo\CasualtiesUnknown_Data\Lang (если у тебя игра загружена на диск C:) ЛИБО в Стиме тыкни на CU в библиотеке, затем Управление...->Просмотреть локальные файлы->CasualtiesUnknown_Data->Lang, и в эту папку (lang) перекинь файл (изначально там уже должен быть файл EN.json)
- Зайди в игру, затем в настройки и настройки языка, после чего выбери "Русский+"
- Всё!
## Как обновить руссификатор
- Выполни первые два шага по установке
- Твоя ОС должна сказать, что файл с таким именем уже существует. Нажми "заменить"/"перезаписать"/ну ты понял
- Иногда игра стирает данные папки lang. В таком случае просто установи руссификатор по инструкции сверху
